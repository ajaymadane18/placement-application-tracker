# Placement Application Tracker System

## About the Project

The Placement Application Tracker System is a web application designed to help students manage and track their job applications in one place.

Students often apply to multiple companies and may forget important details such as company names, job descriptions, application dates, and application status. This project aims to make the job application process easier to organize and manage.

## Features

- **User Registration:** Allows new users to create an account.
- **User Login:** Allows registered users to log in.
- **Dashboard:** Provides a centralized place to view job application information.
- **Application Tracking:** Helps students track their job applications and statuses.
- **Company Details:** Helps organize company names and job descriptions.
- **Application Management:** Keeps job application information organized in one place.
